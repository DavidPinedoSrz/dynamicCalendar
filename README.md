## 🚀 Características

- Migración completa de Vanilla JS → React + TypeScript

- Componentes modernos con TypeScript

- Persistencia de eventos (localStorage)

- Interfaz intuitiva con modal interactivo

- Diseño responsive (funciona en móviles y desktop)

- Animaciones fluidas con CSS moderno

## 🔍 Comparación: Vanilla JS vs React + TypeScript

| Aspecto       |        Vanilla JS        |           React + TypeScript |
| :------------ | :----------------------: | ---------------------------: |
| Organización  |    Código monolítico     |    Componentes reutilizables |
| Tipado        |      Dinámico (JS)       |        Estático (TypeScript) |
| Rendimiento   | DOM manipulation directa |        Virtual DOM eficiente |
| Mantenimiento |    Difícil de escalar    | Fácil extensión (TypeScript) |
| Bundling      |  Ninguno (script tags)   |            Automático (Vite) |

## 🚀 Cómo ejecutar este proyecto

1. Clona el repositorio:

```
git clone https://github.com/DavidPinedoSrz/dynamicCalendar.git
```

2. Instala las dependencias:

```
npm install
```

3. Ejecuta el servidor de desarrollo:

```
npm run dev
```
